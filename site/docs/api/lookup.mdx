```http
GET /v1/lookup/{id}
```

`id` is an IČO (8 digits), a DIČ (10 digits) or an IČ DPH (`SK` + 10 digits). Anything else is
`400 invalid_identifier`.

| Looked up by | Returns |
| --- | --- |
| IČO | One subject. |
| DIČ | The subject with that DIČ. A natural person without an IČO gets only `taxpayer` (DIČ, name, municipality; with taxpayers on also `address` as the DIČ list publishes it), and only for an authenticated key on an instance without anonymous access. |
| IČ DPH | Every subject registered under it: one, or several for a VAT group. |

The highlighted lines are the ones to read first: each section's `state` and `source` (how sure the answer is and
as of when), the VAT paragraph with `payer`, and the attribution you must show with the data.

## Sections

| Section | Source | Holds |
| --- | --- | --- |
| `identity` | RPO | Display name, kind, legal form, dates, address, every registration, the IČO check-digit warning. |
| `tax` | `ds_dsrdp` | DIČ. |
| `vat` | `ds_dphs` | IČ DPH, paragraph, payer, dates. See [VAT status](/concepts/vat). |
| `risk` | `ds_iz_ran`, `ds_dphz`, `ds_dphv`, `ds_dpho` | Reliability index and risk-list entries. |

Each section has a `state` (`present`, `absent`, `unknown`) and a `source` with the dataset, its `asOf` date,
`changedAt`, a content `version` and a `stale` flag. See [Freshness and certainty](/concepts/freshness).

## The register entry on documents

`identity.registrations[]` gives the court and the oddiel/vložka (Commercial Register) or the office and the number
(Trade Register), so a consumer can pre-fill a supplier's legal line. Let the user confirm it. Building the
genitive form of the court name and the exact wording is the consumer's job.

## Status codes

| Code | When |
| --- | --- |
| `200` | Found (some sections may be `unknown` or `stale`). |
| `400` | Not an identifier. |
| `403` | A natural person by DIČ on an instance with anonymous access. |
| `404` | Not found, and every consulted source is fresh. |
| `503` | Not found while a source is stale (`source_stale`), or the mirror is not built yet (`bootstrapping`). |
