<Section title="Running in three commands" lead="Docker with compose, about 10 GB of disk and outbound HTTPS. The first sync takes 10–20 minutes, mostly downloading.">

```sh
git clone https://github.com/accquix/register && cd register/deploy/compose
./make-secrets.sh        # random passwords and one API key, printed once
docker compose up -d     # PostgreSQL, migrate, API on :8080, hourly sync
```

<Section title="Why it exists">

The data is public but scattered across agencies, and the commercial APIs charge per request or per year. The
free Statistical Office API that many tools used stopped answering when the Register of Legal Entities moved to
the Ministry of the Interior in June 2026. Accquix Register reads the official bulk files directly, so your
instance depends on no one's quota.

</Section>

<Section title="What you get">

- **A mirror of the official sources** in your PostgreSQL:
  - the Register of Legal Entities (RPO) of the Ministry of the Interior: names, addresses, legal forms,
    registrations (court, oddiel and vložka, or the trade licensing office and number);
  - the Financial Administration lists: DIČ, IČ DPH and VAT paragraph, the reliability index and the risk lists.
- **Daily updates** that can be interrupted at any moment and resume cleanly.
- **One search box** for a name, IČO, DIČ or IČ DPH. It ignores diacritics and word order, matches the start of
  any word, and can optionally correct typos.
- **A lookup** that returns each part of the answer with its source, its as-of date and a version for change
  detection, and says honestly when it does not know: every section is <State is="present" />,
  <State is="absent" /> or <State is="unknown" />.
- **One Go binary** and plain PostgreSQL 16–18, including managed providers.

</Section>

<Section title="What it is not">

- **No data is published by this project.** Your instance downloads the data from the official sources, and you
  are the controller of your copy under GDPR. See [Data and privacy](/project/data-and-privacy).
- **No public hosted API.** Run your own.
- **No history.** The register keeps the current state of each record and when it last changed.
- **Not a VAT validity oracle.** It reports what the Financial Administration lists say, and as of when. For EU
  VAT numbers, query VIES yourself.

</Section>

<Section title="Status">

Accquix Register is in development and has no release yet. It already syncs the real sources and serves the API.
It is built and maintained by [Accquix](https://accquix.com) and published under the Apache-2.0 licence so that
anyone can run it.

</Section>
