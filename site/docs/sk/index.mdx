<Section title="Spustenie tromi príkazmi" lead="Docker s compose, asi 10 GB miesta na disku a odchádzajúce HTTPS. Prvá synchronizácia trvá 7–20 minút, väčšinou sťahovanie.">

```sh
git clone https://github.com/accquix/register && cd register/deploy/compose
./make-secrets.sh        # náhodné heslá a jeden API kľúč, vypíše sa raz
docker compose up -d     # PostgreSQL, migrate, API na :8080, synchronizácia každú hodinu
```

Len sa chcete pozrieť? `docker compose -f deploy/demo/compose.yaml up` spustí rovnaké API nad fiktívnymi dátami za
pár sekúnd a nič nesťahuje: pozrite [Vyskúšajte demo](/sk/quickstart#vyskúšajte-demo). Alebo to nechajte na svojho AI agenta: prompt nájdete na stránke [Rýchly štart](/sk/quickstart). Na integráciu API
do vašej aplikácie je prompt na stránke [Integrácia do aplikácie](/sk/api/integration).

</Section>

<Section title="Prečo vznikol">

Dáta sú verejné, no roztrúsené medzi úradmi, a komerčné API si účtujú za každú požiadavku alebo ročne. Bezplatné API
Štatistického úradu, ktoré používalo mnoho nástrojov, prestalo odpovedať, keď register právnických osôb v júni 2026
prešiel pod Ministerstvo vnútra. Accquix Register číta oficiálne hromadné súbory priamo, takže vaša inštancia
nezávisí od cudzích limitov.

</Section>

<Section title="Čo získate">

- **Zrkadlo oficiálnych zdrojov** vo vašom PostgreSQL:
  - register právnických osôb (RPO) Ministerstva vnútra: názvy, adresy, právne formy, zápisy (súd, oddiel a
    vložka alebo živnostenský úrad a číslo);
  - zoznamy Finančnej správy: DIČ, IČ DPH a paragraf registrácie, index spoľahlivosti a rizikové zoznamy.
- **Denné aktualizácie**, ktoré možno kedykoľvek prerušiť a ktoré bezpečne pokračujú.
- **Jedno vyhľadávacie pole** pre názov, IČO, DIČ aj IČ DPH. Ignoruje diakritiku a poradie slov, nájde začiatok
  ktoréhokoľvek slova, pri každom kandidátovi ukáže úplnú adresu a voliteľne opraví preklepy.
- **Overenie**, ktoré pri každej časti odpovede uvádza zdroj, dátum aktuálnosti a verziu na sledovanie zmien a
  úprimne povie, keď niečo nevie: každá časť je <State is="present" />, <State is="absent" /> alebo
  <State is="unknown" />.
- **Jeden binárny súbor v Go** a obyčajný PostgreSQL 16–18 vrátane spravovaných poskytovateľov.

</Section>

<Section title="Čo to nie je">

- **Projekt nezverejňuje žiadne dáta.** Vaša inštancia si dáta sťahuje z oficiálnych zdrojov a vy ste
  prevádzkovateľom svojej kópie podľa GDPR. Pozrite [Dáta a súkromie](/sk/project/data-and-privacy).
- **Žiadne verejné hostované API.** Prevádzkujte si vlastné.
- **Žiadna história.** Register drží aktuálny stav každého záznamu a čas jeho poslednej zmeny.
- **Nie je to orákulum platnosti DPH.** Uvádza, čo hovoria zoznamy Finančnej správy, a k akému dátumu. Pri IČ DPH
  iných štátov EÚ sa pýtajte priamo VIES.

</Section>

<Section title="Stav">

**Kandidát na vydanie `1.0.0-rc.1`.** API a ostatné kontrakty sú pre 1.0.0 zmrazené podľa
[politiky stability](/sk/api/stability). Je overený na reálnych dátach vrátane záťažových testov na spravovanom
PostgreSQL. Posledná kontrola pred 1.0.0 je prvé mesačné porovnanie s novým snapshotom RPO okolo 5. decembra 2026.

Vyvíja a udržiava ho [Accquix](https://accquix.com) a zverejňuje pod licenciou Apache-2.0, aby ho mohol
prevádzkovať ktokoľvek.

</Section>
