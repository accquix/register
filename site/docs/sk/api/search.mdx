```http
GET /v1/search?q=<text>&mode=default|fuzzy&limit=<1-20>
```

| Parameter | Predvolené | Význam |
| --- | --- | --- |
| `q` | povinný | Názov alebo identifikátor, 1–200 znakov. |
| `mode` | `default` | `fuzzy` opravuje preklepy; je explicitný, limitovaný a môže byť vypnutý. |
| `limit` | `10` | Najviac 20. |

## Karta výsledku

| Pole | Význam |
| --- | --- |
| `ico` | IČO subjektu (chýba pri zázname bez IČO). |
| `name` | Zobrazovaný názov s diakritikou a právnou formou. |
| `matchedName` | Oficiálny názov, ktorý sa zhodoval, ak nie je zobrazovaným názvom (iný názov živnostníka). |
| `municipality` | Obec sídla alebo miesta podnikania. |
| `address` | Celá adresa sídla alebo miesta podnikania, ako ju zverejňuje RPO: `street`, `buildingNumber`, `postalCode`, `municipality`, `country`. Rovnaká ako pri overení. |
| `kind` | `legal_person`, `sole_trader`, `public_body` alebo `other`. |
| `active` | `false` iba pri zaniknutom subjekte nájdenom podľa identifikátora. |
| `typos` | Len pri preklepoch: počet opráv. |

Vyhľadávanie navrhuje, nerozhoduje. Keď používateľ vyberie kartu, zavolajte
[`GET /v1/lookup/{ico}`](/sk/api/lookup) a získajte celý záznam.

## Správne správanie klienta

- **Oneskorte dopyty počas písania** približne o 120–250 ms. Inak je každé stlačenie klávesu požiadavka.
- **Nikdy automaticky nevyberajte prvý výsledok.** Dva subjekty môžu mať rovnaký názov.
- **Približné vyhľadávanie ponúknite len ako výslovnú akciu**, napríklad „Nič sa nenašlo. Hľadať s preklepmi?“, a
  len ak [`/v1/capabilities`](/sk/reference) uvádza, že je zapnuté.
- Pri `429` počkajte počet sekúnd z hlavičky `Retry-After`.
